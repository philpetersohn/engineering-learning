# AI Application Engineering

Status: **Planned**

The long-term goal is to combine strong full-stack engineering with the ability to build reliable AI-powered applications.

## Learning areas

### LLM fundamentals
- Model APIs and request/response structure.
- Tokens, context windows, and latency.
- Prompt design and structured outputs.
- Limitations, uncertainty, and validation.

### Retrieval-augmented generation (RAG)
- Document ingestion and parsing.
- Chunking strategies and metadata.
- Embeddings and similarity search.
- Vector databases and retrieval.
- Grounding, citations, and evaluation.

### Tool use and agents
- Function/tool calling.
- Workflows versus autonomous agents.
- State, memory, and orchestration.
- Permissions and safe tool execution.
- Retries, failure handling, and observability.

### Production AI applications
- Quality evaluation and regression tests.
- Latency and cost management.
- Security and privacy.
- Monitoring, fallback behavior, and human review.

TeamFlow can become a practical product context for these topics after the relevant backend, database, and cloud foundations are in place.
