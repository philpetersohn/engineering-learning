## Clarification

The learning plan will prioritize a practical full-stack stack:
- React + TypeScript for the frontend.
- Node.js + TypeScript for the backend.
- PostgreSQL + SQL for persistence.

TypeScript is the language; Node.js is the runtime. PostgreSQL is the database; SQL is the query language.
