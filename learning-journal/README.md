# Learning Journal

Use one dated entry per study session or meaningful learning milestone.

## Session format

- **Studied:** topics and resources.
- **Built:** code or exercises completed.
- **Learned:** explain concepts in your own words.
- **Questions / struggles:** gaps and misconceptions.
- **Time spent:** approximate focused study time.
- **Next steps:** the next small, ordered objectives.

## Interview answer format

Preserve both versions:
- **Original answer:** exact learner wording, unchanged.
- **Improved answer:** technically accurate, clearer, and interview-ready.

Never overwrite the original answer when improving it.
